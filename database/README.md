## 🗄️ Base de Données

### Technologies utilisées
- **PostgreSQL** 
- Tables principales : `utilisateurs`, `appareils`, `capteurs_iot`, `consommation`, `alertes`, `objectifs`, `rapports`, `recommandations`

### Fonctionnalités de la BD
- Gestion des utilisateurs (avec rôles USER / ADMIN)
- Suivi en temps réel des appareils connectés via capteurs IoT
- Enregistrement détaillé de la consommation énergétique (time-series)
- Système d'alertes intelligent
- Objectifs d'économie et recommandations personnalisées
- Génération de rapports (PDF / CSV)
